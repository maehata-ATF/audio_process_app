# 🎤 音声処理アプリケーション

ChatGPTのような履歴機能とトークン管理を備えた音声処理アプリケーションです。

## 📋 機能概要

### 1. 議事録要約
- MP3などの音声ファイルをアップロード
- Whisperによる自動文字起こし
- **🆕 AIによる文字起こし自動整形**（誤字脱字修正、意味不明箇所の修正）
- GPTによる議事録要約（Markdown形式）
- 要約結果のファイル出力・ダウンロード
- **🆕 インタラクティブチャット機能**（分析結果についての詳細質問）

### 2. 採用面談分析
- 募集要項をテキストで設定
- 面接音声ファイルをアップロード
- Whisperによる自動文字起こし
- **🆕 AIによる文字起こし自動整形**（誤字脱字修正、意味不明箇所の修正）
- GPTによる3つの分析出力：
  - 面談要約
  - 面接官の質問フィードバック
  - 採用判断材料
- 各分析結果のファイル出力・ダウンロード
- **🆕 インタラクティブチャット機能**（統合分析結果についての詳細質問）

### 3. 🆕 新機能
- **GPTモデル選択機能**: サイドバーでGPT-3.5-turbo、GPT-4、GPT-4o等から選択可能
- **文字起こしブラッシュアップ**: 誤字脱字の自動修正と文脈に基づく意味修正
- **AIチャット機能**: 分析結果について詳細な質問や追加分析が可能
- **チャット履歴保持**: セッション中のチャット履歴を保持

## ✨ 新機能

### 🧠 チャット機能の強化
- **ChatGPTスタイルの履歴表示**: タイムスタンプ付きでチャット履歴を確認可能
- **古い順の履歴管理**: チャット履歴は時系列順に管理
- **会話の継続性**: 前の会話を参照した自然な対話が可能

### 🔧 トークン管理の仕様変更
- **自動制限管理**: コンテキスト上限の50%を超えると古い履歴を自動削除
- **リアルタイム監視**: `tiktoken`を使用したトークン数の随時チェック
- **柔軟な制限**: 履歴が空でも処理を継続

### 🎨 UI改善
- **モード名表示**: 画面最上部にモード名を表示（「議事録要約モード」「採用面談分析モード」）
- **タイトル非表示**: 従来のタイトル表示を削除してスッキリとしたUI
- **トークン使用状況**: 使用率やメッセージ数をリアルタイム表示

## 🚀 セットアップ

### 1. 依存関係のインストール
```bash
pip install -r requirements.txt
```

### 2. 環境変数の設定
`.env`ファイルを作成し、以下の内容を設定してください：

```env
# OpenAI API設定
OPENAI_API_KEY=your_openai_api_key_here

# Whisperモデル設定（base, small, medium, large）
WHISPER_MODEL=base

# GPTモデル設定
GPT_MODEL=gpt-3.5-turbo

# ログレベル設定（DEBUG, INFO, WARNING, ERROR）
LOG_LEVEL=INFO
```

### 3. ffmpegのインストール
音声ファイル処理にffmpegが必要です：

**Windows:**
```bash
# Chocolateyを使用
choco install ffmpeg

# または公式サイトからダウンロード
# https://ffmpeg.org/download.html
```

**macOS:**
```bash
brew install ffmpeg
```

**Linux:**
```bash
sudo apt update
sudo apt install ffmpeg
```

## 🎯 使い方

### アプリケーションの起動
```bash
streamlit run app.py
```

### 議事録要約モード
1. サイドバーで「議事録要約」を選択
2. 音声ファイルをアップロード（MP3, WAV, M4A, FLAC, OGG対応）
3. GPTモデルを選択
4. 「議事録要約を開始」をクリック
5. 結果をタブで確認・ダウンロード
6. AIチャットで詳細質問

### 採用面談分析モード
1. サイドバーで「採用面談分析」を選択
2. 募集要項を入力
3. 面接音声ファイルをアップロード
4. GPTモデルを選択
5. 「面接分析を開始」をクリック
6. 各タブで結果を確認
7. AIチャットで詳細質問

## 💬 チャット機能

### 特徴
- **履歴保持**: ChatGPTのように会話履歴が保持されます
- **タイムスタンプ**: 各メッセージに時刻が表示されます
- **コンテキスト理解**: 分析結果を踏まえた回答が可能
- **トークン管理**: 使用量を監視し、自動で古い履歴を削除

### 使用例
```
ユーザー: この会議の最も重要な決定事項は何ですか？
アシスタント: 議事録を確認すると、最も重要な決定事項は...

ユーザー: その決定に至った理由を教えてください
アシスタント: 先ほどの決定について、会議では以下の理由が...
```

## 📊 トークン管理

### 仕様
- **制限値**: 各モデルのコンテキスト上限の50%
- **監視方法**: `tiktoken`ライブラリによる正確なカウント
- **削除ルール**: 制限超過時に最古のメッセージから削除
- **継続性**: 履歴が空でも処理は継続

### 対応モデル
- `gpt-3.5-turbo`: 4,096トークン（制限: 2,048）
- `gpt-4`: 8,192トークン（制限: 4,096）
- `gpt-4-turbo`: 128,000トークン（制限: 64,000）
- `gpt-4o`: 128,000トークン（制限: 64,000）

## 📊 ログ機能

### ログファイルの場所
- **保存先**: `logs/`フォルダ
- **ファイル名**: `app_YYYYMMDD.log`（日付ごとに自動作成）
- **形式**: タイムスタンプ、モジュール名、ログレベル、関数名、メッセージ

### ログレベル設定
`.env`ファイルで`LOG_LEVEL`を設定できます：
- `DEBUG`: 詳細なデバッグ情報
- `INFO`: 一般的な処理情報（デフォルト）
- `WARNING`: 警告メッセージ
- `ERROR`: エラーメッセージのみ

### ログで記録される情報
- アプリケーションの起動・終了
- ファイルアップロード情報
- 音声処理の進行状況
- OpenAI API呼び出し詳細
- エラーの詳細情報とスタックトレース

## 🔧 トラブルシューティング

### よくある問題と解決方法

**1. ffmpegエラー（最も一般的）**
```
音声処理に必要なffmpegが見つかりません
```
- **原因**: ffmpegがインストールされていない
- **解決方法**: 上記のffmpegインストール手順に従ってインストール
- **確認**: `ffmpeg -version` でバージョンが表示されることを確認
- **ログ確認**: `logs/app_YYYYMMDD.log`でffmpegの検索状況を確認

**2. OpenAI APIキーエラー**
```
⚠️ OpenAI APIキーが設定されていません
```
- 環境変数 `OPENAI_API_KEY` が正しく設定されているか確認
- APIキーが有効で残高があるか確認
- **ログ確認**: `logs/app_YYYYMMDD.log`でAPIキー設定状況を確認

**3. Whisperモデル読み込みエラー**
```
Whisperモデルの読み込みに失敗しました
```
- インターネット接続を確認（初回はモデルダウンロードが必要）
- ディスク容量を確認
- **ログ確認**: ログファイルでモデル読み込みの詳細エラーを確認
- `config.py`や`.env`で軽量モデル（tiny）に変更を試行

**4. 音声ファイルのエラー**
```
サポートされていないファイル形式です
```
- 対応形式：MP3, WAV, M4A, FLAC, OGG
- ファイルサイズ：200MB以下
- **ログ確認**: ファイル情報とエラー詳細をログで確認

**5. 文字起こしエラー**
```
文字起こしに失敗しました
```
- **ログ確認**: `logs/app_YYYYMMDD.log`でWhisperの詳細エラーを確認
- 音声ファイルが破損していないか確認
- 一時的なディスク容量不足の可能性
- CPU使用率が高い場合は時間をおいて再試行

**6. GPT分析エラー**
```
要約生成に失敗しました
```
- **ログ確認**: OpenAI API呼び出しの詳細エラーを確認
- APIの利用制限に達している可能性
- トークン数が上限を超えている可能性
- ネットワーク接続を確認

**7. Whisper FP16警告**
```
FP16 is not supported on CPU; using FP32 instead
```
- **これは正常な警告です**（CPU環境では自動的にFP32を使用）
- 処理に影響はありません
- アプリケーションで警告は抑制済み

### ログを使った問題調査

1. **ログファイルの確認**
   ```bash
   # 最新のログファイルを確認
   cat logs/app_$(date +%Y%m%d).log
   
   # エラーのみを表示
   grep ERROR logs/app_$(date +%Y%m%d).log
   
   # ffmpeg関連のログを確認
   grep ffmpeg logs/app_$(date +%Y%m%d).log
   ```

2. **詳細ログの有効化**
   ```bash
   # .envファイルでDEBUGレベルに設定
   LOG_LEVEL=DEBUG
   ```

3. **処理フローの確認**
   - ログでどの段階で失敗しているかを特定
   - 入力ファイルの情報とエラーの関連性を調査
